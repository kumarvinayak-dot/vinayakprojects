🎨 COLOR CODING
═══════════════════════════════════════════════════════════════════════════

The table uses color-coded rows for instant recognition:

🔵 BLUE   = Identical files (present in both folders)
🔴 RED    = Missing in right folder (only in Folder 1)
🟢 GREEN  = Missing in left folder (only in Folder 2)
🟡 YELLOW = Additional/New files (truly new, not version updates)

═══════════════════════════════════════════════════════════════════════════
🏷️ STATUS BADGES
═══════════════════════════════════════════════════════════════════════════

Clear visual indicators for each file:

✓ Identical          → File exists in both folders
← Missing in Right   → Only in Folder 1 (version update)
→ Missing in Left    → Only in Folder 2 (version update)
🆕 Additional Right  → Truly NEW file in Folder 2
🆕 Additional Left   → Truly NEW file in Folder 1

🚀 HOW TO USE
═══════════════════════════════════════════════════════════════════════════

1. Start the web UI:
   start_web_gui.bat

2. Run your comparison (e.g., BN343 vs BN344 lightsaber.zip)

3. Open the HTML report

4. Look for the navigation menu at the top:
   ┌──────────────────────────────────────┐
   │ 📑 Quick Navigation                  │
   │                                      │
   │ 📊 Detailed Comparison Table  ← NEW! │
   │ 🆕 Additional/New Files              │
   │ ❌ Missing from Folder 2             │
   │ ✅ Missing from Folder 1             │
   │ ✓ Exact Matches                      │
   └──────────────────────────────────────┘

5. Click "📊 Detailed Comparison Table"

6. Instantly see ALL files in one table with color coding!

🎯 REAL-WORLD EXAMPLE
═══════════════════════════════════════════════════════════════════════════

SCENARIO: You need to know what changed between BN343 and BN344

OLD WAY (5+ minutes):
  1. Scroll to "Missing from Folder 2" section
  2. Read list of removed files
  3. Scroll to "Missing from Folder 1" section
  4. Read list of added files
  5. Try to figure out which are version updates vs truly new
  6. Scroll to "Exact Matches"
  7. Verify unchanged files
  8. Mentally piece everything together

NEW WAY (30 seconds):
  1. Click "📊 Detailed Comparison Table"
  2. Scan the table:
     • Yellow rows = NEW files
     • Red/Green rows = Version updates
     • Blue rows = Unchanged
  3. DONE! ✓

═══════════════════════════════════════════════════════════════════════════
💡 PRO TIPS
═══════════════════════════════════════════════════════════════════════════

1. Look for YELLOW rows first
   → These are truly NEW files (not version updates)

2. Differences appear at the TOP
   → You don't need to scroll through matches to find changes

3. Empty cell = File doesn't exist in that folder
   → Shows as "—" for clarity

4. Status badges are color-coded too
   → Match the row background for consistency

5. Use Ctrl+F (Find) in the browser
   → Search for specific file names in the table
