✅ NEW FEATURE: Automatic cleanup of existing server instances!

The server now automatically stops any running instances before starting.
No more "port already in use" errors!

═══════════════════════════════════════════════════════════════════════════
🚀 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════

When you start the server, it automatically:

1. ✓ Scans for existing builtin_server.py processes
2. ✓ Gracefully stops them
3. ✓ Waits for cleanup to complete
4. ✓ Starts the new server instance

All in ONE command!

═══════════════════════════════════════════════════════════════════════════
💻 USAGE
═══════════════════════════════════════════════════════════════════════════

OPTION 1: Default (localhost:5000)
> start_web_gui.bat

OPTION 2: Custom IP and Port
> py builtin_server.py --host 10.19.164.180 --port 8080 --skip-demos

OPTION 3: Quick Restart Script
> restart_server.bat

🔧 TECHNICAL DETAILS
═══════════════════════════════════════════════════════════════════════════

The server uses psutil library to:
- Find all Python processes
- Filter for builtin_server.py instances
- Gracefully terminate them
- Wait for cleanup before starting

If psutil is not available:
- Server still starts normally
- Manual cleanup may be needed (rare)

═══════════════════════════════════════════════════════════════════════════
📦 REQUIREMENTS
═══════════════════════════════════════════════════════════════════════════

For auto-cleanup to work, install psutil:
> pip install psutil

If not installed:
- Server will still work
- Auto-cleanup will be skipped
- You'll see a note in output

❓ FAQ
═══════════════════════════════════════════════════════════════════════════

Q: What if multiple people are running the server?
A: Each user's server runs independently. Only YOUR old instances are killed.

Q: Does it affect other Python programs?
A: No! Only processes running builtin_server.py are affected.

Q: What if I want to run multiple servers?
A: Use different ports for each. They won't interfere with each other.

Q: Can I disable auto-cleanup?
A: It's automatic but graceful. If you need multiple instances, use different
   ports (--port 8080, --port 8081, etc.)
