PROGRESS TRACKING AND TIMEOUT HANDLING - FEATURE SUMMARY
================================================================================

WHAT WAS ADDED:

1. REAL-TIME PROGRESS BAR IN WEB UI
   - Visual progress bar showing % completion
   - Files processed count (e.g., "1508 / 2000")
   - Current file being compared
   - Estimated time remaining (dynamically calculated)
   - Auto-scrolls to keep progress visible

2. AUTOMATIC TIMEOUT HANDLING
   - Overall comparison timeout: 2 hours default
   - Per-file timeout: 10 minutes default
   - Configurable via FolderComparer properties
   - Generates partial report before exiting on timeout

3. ERROR REPORTING IN COMPARISON REPORTS
   - Report header shows comparison status: "COMPLETE" or "INCOMPLETE/ERROR"
   - Error messages included in report
   - Files processed count before error
   - Clear note that report is partial

4. NETWORK ERROR RESILIENCE
   - Automatic retry on network errors
   - Network connectivity checks before operations
   - Graceful exit with report generation on network failure

5. PROGRESS API ENDPOINT
   - `/progress` endpoint returns JSON with current status
   - Updates every second
   - Provides all progress information to UI

HOW TO USE:
================================================================================

WEB UI:
1. Start the server:
   .\.venv\Scripts\python.exe builtin_server.py --host 0.0.0.0 --port 5000

2. Open browser: http://localhost:5000

3. Enter folder paths and click "Run comparison"

4. Progress bar appears automatically showing:
   - Percentage complete
   - Files processed
   - Current file
   - Estimated time remaining

5. If error occurs:
   - Error message displays in red box
   - Partial report is generated
   - Report includes error details

COMMAND LINE:
python main.py compare "folder1" "folder2" -m full

Progress logged to console:
  Progress: 100/2000 files processed (5.0%) - ETA: 450s

================================================================================
CUSTOMIZING TIMEOUTS:
================================================================================

In Python code:

from folder_compare import FolderComparer

comparer = FolderComparer(folder1, folder2)
comparer.comparison_timeout = 3600  # 1 hour overall
comparer.file_timeout = 300  # 5 minutes per file
results = comparer.compare_folders()

================================================================================
ERROR HANDLING SCENARIOS:
================================================================================

1. TIMEOUT SCENARIO:
   - Comparison takes >2 hours
   - Tool stops comparison
   - Generates partial report with error:
     "Error: Comparison timeout after 7200 seconds"
     "Files processed before error: 1508/2000"

2. FILE STUCK SCENARIO:
   - Single file takes >10 minutes
   - Tool logs error for that file
   - Continues to next file
   - Report includes timeout info

3. NETWORK ERROR SCENARIO:
   - Network path becomes unavailable
   - Tool retries 3 times
   - If all fail, generates partial report
   - Report includes network error details

4. KEYBOARD INTERRUPT:
   - User presses Ctrl+C
   - Tool catches interrupt
   - Generates partial report
   - Report shows "interrupted by user"
