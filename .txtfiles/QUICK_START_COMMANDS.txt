TROUBLESHOOTING
================================================================================

If you get "python is not recognized":
  - Use "py" instead of "python"
  - Or use full path: C:\Python3X\python.exe

If network paths don't work:
  - Run diagnostics: py main.py --diagnose --base-path "\\server\share"
  - Map network drive first: net use Z: \\server\share
  - Use --use-local-copy flag

If comparison is slow:
  - Use --use-local-copy for network folders
  - Use --simple-names for quick file list comparison
  - Use --naming-convention to skip content comparison
