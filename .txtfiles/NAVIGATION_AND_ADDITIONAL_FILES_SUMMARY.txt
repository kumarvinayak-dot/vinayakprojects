✅ WHAT'S NEW

1. 📑 NAVIGATION MENU WITH HYPERLINKS
   - Appears at the top of every HTML report
   - Clickable links to jump to any section instantly
   - Color-coded for easy identification:
     • Orange: Additional/New Files
     • Red: Missing from Folder 2
     • Green: Missing from Folder 1
     • Blue: Exact Matches
   - Shows file counts for each section

2. 🆕 ADDITIONAL FILES DETECTION
   - Smart algorithm identifies truly NEW files
   - Separates NEW files from version updates
   - Example:
     ❌ Version update: app-10.1.0.319.jar → app-10.1.0.344.jar
     ✅ New file: scriptingextensions-setup-extensions.jar

3. 🎨 ENHANCED MISSING FILES SECTION
   - Prominent display with clear titles
   - "Missing from Folder 2 - Only in Folder 1"
   - "Missing from Folder 1 - Only in Folder 2"
   - Each file shown with full path
   - Color-coded badges (RED for removed, GREEN for added)

4. 🔗 SECTION ANCHORS
   All sections now have clickable IDs:
   - #additional-files
   - #missing-folder2
   - #missing-folder1
   - #exact-matches

HOW TO USE
═══════════════════════════════════════════════════════════════════════════

1. Start the web UI:
   start_web_gui.bat

2. Run your comparison (e.g., BN343 vs BN344)

3. Open the HTML report

4. Use the navigation menu:
   - Click "🆕 Additional/New Files" → Jump directly to new files
   - Click "❌ Missing from Folder 2" → See what's removed
   - Click "✅ Missing from Folder 1" → See what's added
   - Click "✓ Exact Matches" → See unchanged files

5. Quickly identify:
   - Which files are truly NEW (orange ADDITIONAL badge)
   - Which files are version updates (normal listing)
   - Missing files with full paths
