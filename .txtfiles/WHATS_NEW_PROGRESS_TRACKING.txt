================================================================================
WHAT'S NEW: PROGRESS TRACKING AND TIMEOUT HANDLING
================================================================================

Your comparison tool now shows exactly what's happening during long comparisons
and never gets "stuck" - it will always generate a report, even when encountering
errors!

================================================================================
KEY FEATURES
================================================================================

1. REAL-TIME PROGRESS BAR (Web UI)
   
   When you run a comparison at http://localhost:5000, you'll see:
   
   [====================>        ] 75.3%
   
   Status: Running...
   Files processed: 1508 / 2000
   Current file: path/to/current/file.jar
   Estimated time remaining: 2m 15s
   
   ✓ Updates every second
   ✓ Shows exactly which file is being processed
   ✓ Calculates estimated time remaining
   ✓ Auto-scrolls to stay visible

2. AUTOMATIC TIMEOUT PROTECTION
   
   Your comparisons won't run forever:
   
   ✓ Overall timeout: 2 hours maximum
   ✓ Per-file timeout: 10 minutes maximum
   ✓ Generates partial report if timeout occurs
   ✓ Report shows exactly what happened
   
   Example report with timeout:
   
   *** COMPARISON STATUS: INCOMPLETE/ERROR ***
   Error: Comparison timeout after 7200 seconds
   Files processed before error: 1508/2000
   Note: This is a PARTIAL report with results up to the point of error

3. NETWORK ERROR HANDLING
   
   If network paths become unavailable:
   
   ✓ Automatic retry (3 attempts)
   ✓ Partial report generated
   ✓ Clear error message in report
   ✓ You don't lose all your work!

4. CONSOLE PROGRESS (Command Line)
   
   When running from command line:
   
   Progress: 100/2000 files processed (5.0%) - ETA: 450s
   Progress: 200/2000 files processed (10.0%) - ETA: 405s
   
   ✓ Shows progress every 100 files
   ✓ Includes ETA

================================================================================
HOW TO USE
================================================================================

OPTION 1: Web Interface (Recommended)
--------------------------------------

1. Start server:
   py builtin_server.py --host 0.0.0.0 --port 5000

2. Open browser:
   http://localhost:5000

3. Enter your folder paths and click "Run comparison"

4. Watch the progress bar!
   - You'll see real-time updates
   - Estimated time remaining
   - Current file being processed

OPTION 2: Command Line
----------------------

py main.py compare "folder1" "folder2" -m full

Progress appears in console output.

================================================================================
TROUBLESHOOTING
================================================================================

Q: Progress bar not showing?
A: Make sure you're using the WEB UI at http://localhost:5000
   (not command line)

Q: ETA shows "Calculating..." for a long time?
A: Needs at least 1 file to be processed first
   Usually appears within 10 seconds

Q: Comparison still seems slow?
A: Try these optimizations:
   - Use --use-local-copy for network paths
   - Use --deep-compare-if-different flag
   - See: QUICK_START_COMMANDS.txt section 13

Q: Want longer/shorter timeouts?
A: Edit timeouts in Python:
   comparer.comparison_timeout = 3600  # 1 hour
   comparer.file_timeout = 300  # 5 minutes
