ISSUE:
------
When comparing JAR files using the web UI, an AttributeError was thrown:

  AttributeError: 'ArchiveContentsComparer' object has no attribute 'processed_files'

This occurred when comparing:
  \\DVCIISILON01\cm_share3\10.0.1\AmdocsCRM10.0.PB1.HFB21_release\release\SDK_linux\SDK_CRM_10.0.1.21_linux64_20250908_1434.jar

ROOT CAUSE:
-----------
Progress tracking properties were only added to FolderComparer class, but the
web UI (builtin_server.py) tries to access these properties on ALL comparer types:
  - ArchiveContentsComparer
  - NamingConventionComparer
  - JarManifestComparer

When using archive comparison mode, the web UI stored ArchiveContentsComparer
in the global comparison_progress dict, but ArchiveContentsComparer didn't have
the progress tracking properties.

FIX APPLIED:
------------
Added progress tracking properties to ALL comparer classes:

1. ArchiveContentsComparer (line 1551-1558)
2. NamingConventionComparer (line 1124-1131)
3. JarManifestComparer (line 2441-2448)

Properties added to each:
  - total_files: int = 0
  - processed_files: int = 0
  - current_file: str = ""
  - progress_percentage: float = 0.0
  - estimated_time_remaining: int = 0
  - comparison_start_time: float | None = None
  - comparison_error: str | None = None
