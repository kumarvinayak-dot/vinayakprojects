The server now has built-in auto-restart logic!
No need for separate cleanup commands anymore.

═══════════════════════════════════════════════════════════════════════════
🚀 JUST RUN ONE COMMAND
═══════════════════════════════════════════════════════════════════════════

For localhost (default):
> start_web_gui.bat

For network access:
> restart_server.bat

OR custom:
> py builtin_server.py --host YOUR_IP --port YOUR_PORT --skip-demos

═══════════════════════════════════════════════════════════════════════════
✨ WHAT HAPPENS AUTOMATICALLY
═══════════════════════════════════════════════════════════════════════════

1. ✓ Finds any running builtin_server.py instances
2. ✓ Stops them gracefully
3. ✓ Waits for cleanup
4. ✓ Starts fresh server
5. ✓ Shows you the URL to access

ALL IN ONE COMMAND!
