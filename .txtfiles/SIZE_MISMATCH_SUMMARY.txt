========================================
SIZE MISMATCH FEATURE - QUICK SUMMARY
========================================

WHAT'S NEW:
-----------
✓ New "Size Mismatches" section in archive comparison HTML reports
✓ Shows files with different sizes between Archive 1 and Archive 2
✓ Professional table format with formatted sizes (B, KB, MB, GB)
✓ Calculates differences and percentage changes
✓ Navigation hyperlink for quick access

FEATURES:
---------
1. Navigation Link
   - Shows in Quick Navigation menu
   - Example: "📏 Size Mismatches (45)"
   - Click to jump directly to the section

2. Detailed Table Display
   - File name
   - Size in Archive 1 (right-aligned, monospace)
   - Size in Archive 2 (right-aligned, monospace)
   - Difference row showing:
     * Absolute difference
     * Percentage change
     * Direction (+/-)

3. Smart Size Formatting
   - Bytes: "1234 B"
   - Kilobytes: "15.42 KB"
   - Megabytes: "2.35 MB"
   - Gigabytes: "1.05 GB"

-----------
1. Start server: py builtin_server.py --host 10.19.164.180 --port 8080 --skip-demos
2. Run Archive contents comparison
3. Open HTML report
4. Click "📏 Size Mismatches (X)" in navigation menu
5. View detailed size comparison table
