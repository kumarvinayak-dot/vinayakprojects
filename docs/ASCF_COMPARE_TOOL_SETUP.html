Comparison Tool — Setup

Install and run from Comparison Tool.zip — localhost only (Developed by Vinayak Srivastava)

Localhost-only mode

Each user installs and runs the tool on their own PC. The server listens on localhost only (127.0.0.1). Other computers cannot connect. No shared network HTTP/HTTPS URLs are used.

Install (one time)

  1. Copy Comparison Tool.zip to your PC (e.g. Desktop or Downloads).
  2. Right-click the ZIP → Extract All…
  3. Open the extracted Comparison Tool folder.
  4. Double-click setup.cmd in the extracted folder.
  5. Wait for setup to finish. It will:
    • Locate Python 3.10+ on your PC
    • Create a Python virtual environment (.venv) in the same folder
    • Install packages from requirements.txt
    No files are copied elsewhere. This may take 5–15 minutes depending on network speed.
  6. When you see Installation complete, press Enter.

No Desktop or Start Menu shortcuts are created. Use start_server.bat in the install folder.

Use the tool (every day)

  1. Double-click ASCF Compare Tool - Start on your Desktop.
  2. Wait a few seconds — your browser should open automatically.
  3. If it does not, open manually: 
    http://localhost:5000/crm
  4. Enable Build Comparison, select your application, enter build paths, and run comparisons.
  5. To stop the server, use Stop Server from the Start Menu or run STOP_SERVER.bat in the install folder.

Optional: HTTPS (self-signed)

For Environment Validation (SSH password over HTTPS):

  1. Open PowerShell in the install folder.
  2. Run: 
    powershell -ExecutionPolicy Bypass -File scripts\generate_https_cert.ps1
  3. Restart with ASCF Compare Tool - Start.
  4. Use: https://localhost:5443/crm (browser may warn about self-signed certificate).

Uninstall

  1. Stop the server (Stop Server shortcut or STOP_SERVER.bat).
  2. Run Uninstall ASCF Compare Tool.bat in the install folder.
  3. Type YES when prompted.

Troubleshooting

“Python 3.10+ not found”

Install Python from python.org and enable Add Python to PATH, then run setup.cmd again.

Browser shows “Can’t reach this page”

  1. Run ASCF Compare Tool - Start again.
  2. Run CHECK_STATUS.bat in the install folder.
  3. Confirm you use http://localhost:5000/crm (not an IP address or another PC’s name).

Port 5000 already in use

  1. Run STOP_SERVER.bat.
  2. Start again with ASCF Compare Tool - Start.

pip install fails (no internet / proxy)

Ask your team lead for offline wheel packages and manual setup (see LOCAL_USER_SETUP.md).

Security notes

  • The tool binds to 127.0.0.1 only — not accessible from other PCs on the network.
  • No shared network URLs are displayed or required.
  • Do not copy .venv or .env from another user’s machine.
