## Quick start

1. Extract **`Comparison Tool.zip`** anywhere on your PC.
2. Double-click **`setup.cmd`** in the extracted folder (installs `.venv` only — no file copy).
3. Run **`start_server.bat`** in the same folder.
5. Open **http://localhost:5000/crm** in your browser.

No Desktop or Start Menu shortcuts are created during install.
