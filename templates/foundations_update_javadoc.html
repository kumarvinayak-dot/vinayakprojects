📝 Update Javadoc.html Automatically

This will add a new hotfix entry to the version Javadoc file (e.g. 9_Javadoc.html in Version9\API).

ℹ️ What this does:

  • Opens the Javadoc file at \\usstlfounds01\ascf\userguides\VersionX\API\X_Javadoc.html (Version8, Version9, Version10, Version10_1, or Version{major})
  • Finds the previous HF entry (e.g., 9.22.0.pb01_hf12)
  • Adds a new entry below it (e.g., 9.22.0.pb01_hf13) with the same structure
