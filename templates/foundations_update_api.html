🔧 Manual API Update Instructions

Follow these steps to manually update the API:

  1. Open the Foundation Admin site:
    http://foundations/asplib/backOffice.asp
  2. Click on Administrative Tools
  3. Select the ASCF Product Version from the dropdown
  4. Click Add New Release
  5. Fill in the required fields:
    • New Hotfix Version (e.g., 10.24.0.pb01_hf09)
    • Release Date (e.g., 2026-02-17)
    • Download URL (e.g., 10240pb01hf09_download.html)
    • Release Notes URL (e.g., ReleaseNotes/relnotes10_24_0_pb01_hf09.pdf)
  6. Click Add Hotfix to save
