Comparison Tool — Installation Instructions

Developed by Vinayak Srivastava

Localhost-only mode

Each user installs and runs the tool on their own PC. The server listens on localhost only (127.0.0.1). Other computers cannot connect. No shared network HTTP/HTTPS URLs are used.

Markdown version: INSTALL_INSTRUCTIONS.md

What you receive

Your team lead shares one file:

Install (one time)

  1. Copy Comparison Tool.zip to your PC (e.g. Desktop, Downloads, or C:\).
  2. Right-click the ZIP → Extract All… (or unzip with 7-Zip / WinRAR).
  3. Open the extracted Comparison Tool folder (paths with spaces are fine).
  4. Double-click INSTALL.cmd in that folder (setup.cmd still works for compatibility).
  5. Wait for setup to finish. It creates .venv and installs packages with a clean pip install (no cache). This may take 5–15 minutes.
  6. When you see Installation complete, press Enter.

No Desktop or Start Menu shortcuts are created. Use the batch files in the extracted folder.

Use the tool (every day)

  1. Open the install folder and double-click launch_comparison_tool.bat (or start_server.bat).
  2. Wait a few seconds — your browser should open http://localhost:5000/crm automatically.
  3. If it does not, open manually: 
    http://localhost:5000/crm

    Aliases: /ascf, /uxf, /dex (same page).

  4. Run build comparison or environment validation (see below).
  5. To stop the server, run STOP_SERVER.bat in the install folder.

Run comparisons (all applications)

One web UI supports ASCF, CRM/AMSS, UXF/OMNI, and DEX. Single URL: http://localhost:5000/crm

Quick steps

  1. Start the server (launch_comparison_tool.bat).
  2. Open http://localhost:5000/crm.
  3. Enable Build Comparison.
  4. Select exactly one application: ASCF, CRM/AMSS, UXF/OMNI, or DEX.
  5. Enter Old and New build paths (UNC), or use Load … base paths buttons.
  6. Configure options for that application (table below).
  7. Click Run comparison — use Console Output for live logs.
  8. Open the HTML report when the run completes.

Application-specific notes

ApplicationPaths / inputsOptions
ASCF Old vs new ASCF build roots. Load ASCF base paths. Full content, naming convention, archives, or FOSS/Foundation.
CRM / AMSS Old vs new CRM/AMSS folders. Load CRM or AMSS base paths. Fast full compare; optional ClfyAgent nested compare; CRM Nexus TAR verification.
UXF / OMNI Old vs new UXF/OMNI roots. Load UXF or OMNI base paths. Full folder comparison.
DEX Nexus previous/latest versions for digital-playbook and/or digital-webapp-ces. Downloads from Nexus and compares artifacts automatically.

Environment validation

Use Environment Validation on the home page to SSH to a Linux host and verify deployment — for any application.

Reports

  • HTML reports: \\<your-pc>\c$\crm_compare_reports
  • Temp during compare: \\<your-pc>\c$\crm_compare_temp
  • Optional CRM Java diffs: C:\cfr-0.152.jar

Uninstall

  1. Stop the server (STOP_SERVER.bat).
  2. Run Uninstall Comparison Tool.bat in the install folder.
  3. Type YES when prompted.

Troubleshooting

“Python 3.10+ not found”

Install Python from python.org and enable Add Python to PATH, then run INSTALL.cmd again.

Browser shows “Can’t reach this page”

  1. Run start_server.bat again.
  2. Run CHECK_STATUS.bat in the install folder.
  3. Confirm you use http://localhost:5000/crm (not an IP address or another PC’s name).

Port 5000 already in use

  1. Run STOP_SERVER.bat.
  2. Start again with start_server.bat.

pip install fails (no internet / proxy)

Ask your team lead for offline wheel packages and manual setup (see LOCAL_USER_SETUP.md in the project).

Confusing pip messages during install

INSTALL.cmd uses pip install --no-cache-dir so you should not see “Cache entry deserialization failed” warnings. Delete .venv and run INSTALL.cmd again if install fails.

Windows blocks INSTALL.cmd

Right-click INSTALL.cmd → Run as administrator, or open Command Prompt in the extracted folder and run:

INSTALL.cmd
